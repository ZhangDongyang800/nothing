日期：2026-11-25　范围：`site/src/themes/hall/rogue`、`site/src/themes/hall/legion`

第三轮把两台的造型与特效重做了一遍。作者实机跑了之后附三张截图，指出六处仍然不到位的地方。
这一轮不再加新造型，只解决**"看得见 / 看得清 / 不挡路"**——上一轮做过头的地方，和上一轮漏掉的地方。

## 二、两个真 bug（不是审美问题）

### 2.1 候选区兵牌被灰块盖满

作者截图里点将台两格是纯灰实心板，红箭头指着。探针量 DOM 计算样式：

```
.lg-slot        68 × 68
.lg-slot-lv     59 × 61   ← 几乎盖满整张卡
```

根因是两层 CSS 打架：

- `legion.css:507` 给等级角标设了 `position:absolute; left:2px; bottom:1px; background:var(--rar)`
- `legion-v6.css:814` 又设了 `right:3px; top:2px`，**没有重置 left/bottom**

绝对定位四边齐全 + `width:auto` = 拉满父盒，再叠上品质色背景就成了实心板。
普通品质是灰色，正是作者看到的那块灰。`.lg-slot em`（锐标记）同样中招，被拉成一块金板——
这同时解释了第 5 条"精锐普通没有区分"：区分标识本身被自己撑成了色块。

修复追加在 `legion-v7.css` 末尾（最高层），四边收回单角、`width/height:auto`，做成带墨边硬阴影的小角牌。
实测 **59×61 → 18×15**，`em` 17×14。

### 2.2 兵牌等级 1~3 级读不出来

`draw.ts` 的等级角标：

```ts
ctx.fillStyle = u.lv >= 4 ? color : '#fffdf7'   // 低级 = 纸底
...
ctx.fillStyle = '#fff8e8'                        // 字 = 纸色
```

纸底配纸色字，**1~3 级的数字是隐形的**。作者说"升级合成没有明显清晰的视觉变化"，
最直接的一条就是：合完了，等级数字压根没显示出来。4 级以上因为底色换成品质色才看得见。

改成低级角标落墨字 + 一道品质色细边。

## 三、墨潮

### 3.1 构筑条：信息保留，占位从 ~100px 降到 28px

原来 `.rg-build` 是 flex column 两行（武器行 / 被动行）。Lv22 时 6 武器 + 10 被动铺成三行，
压掉左上近 100px 战场——正是作者截图里那堵标签墙。

改法（`rogue.css` v9 段 + `ui.ts`）：

- 两行并排：`flex-direction:row; flex-wrap:wrap; max-width:min(78%,900px)`
- chip 只留**图标 + 等级**，`b`（名字）`display:none`
- 名字收进 `::after` 绝对定位悬停浮标，**不参与布局**，展开不会再压战场
- chip 加 `data-name` / `title`，鼠标悬停与原生 tooltip 都能读到全名
- 被动行左缘一道细墨线分隔；≤900px 图标缩到 17×17

实测（1440×900，6 武器 Lv5 + 10 被动 Lv4，共 16 chip）：

```
build  { w:682, h:28, chips:16, canvasH:848, coverPct:3.3 }
hover  "飞白 Lv.5"
```

一行、28px、占画布 **3.3%**。信息一条没少。

### 3.2 敌弹统一朱红

原来 `ctx.fillStyle = s.color`，颜色由 `enemyShot()` 的调用方传入，多数是墨色。
结果墨卒、碑灵打出来的是黑菱形，跟满地墨点、碎墨、墨渍混在一起——
**"必须躲的东西"跟背景同色**，这是可读性事故，不是风格选择。

改成固定四层，与来源色解耦：

1. 速度拖尾（`spd/170` 决定长度，淡朱）
2. 纸垫椭圆 `rgba(255,253,247,.95)`，比原来大一圈
3. 朱体 `#d1372c`
4. 深朱墨边 `#5e1712` + 前缘亮芯 `#ffd9a8`

任何底色上都跳得出来，且保留方向感。

### 3.3 宝箱掉率

三条渠道叠在一起，中后期几乎每十几秒一只，宝箱从"事件"变成了"背景音"。

| 渠道 | 原 | 现 |
|---|---|---|
| 精英死亡 | 0.55 | **0.25** |
| 定时掉落间隔 | 72s | **110s** |
| 清完一队墨将 | 必掉 | **0.5**，另一半改撒 4 堆墨钱 |
| Boss 击杀 | 必掉 | 不变（里程碑） |
| `treasure` 事件 | 必掉 | 不变（玩家主动选的） |

清队不掉箱子时给墨钱 + "墨将清完 · 墨钱撒了一地"，奖励感不丢，只是不再每次都开面板打断节奏。

## 四、纸上军团

前提：v3 的"文字棋子 + 方格棋盘"是刻意定下的核心识别，本轮全部改动保留汉字主体，没有改回小人插画。

### 4.1 等级刻度：把品质书签改成五格计量条

这是"合成没反馈"的根子——Lv1 和 Lv4 的牌除了角标数字几乎一模一样，
而角标数字又因为 2.2 的 bug 在 1~3 级隐形。

左侧原来是一条实心品质条，现在改成 **5 段刻度，亮几格就是几级**：

- 亮格用纸白 `#fff8e8`（墨牌上只有纸色跳得出来，品质色压墨底等于看不见）
- 每格左缘留一道品质色，稀有度信息不丢
- 满级五格转金 `#ffd166`
- 暗格 `rgba(255,248,232,.13)`，能数出总格数

第一版用品质色画亮格，截图一看在墨牌上几乎不可见，改成纸白才成立。

配套：3 级起加一道内框（专精之后牌面"更成型"），5 级加四角金饰 + 一圈呼吸金框。

### 4.2 精锐：小字 → 朱红方印

原来 `veteran` 只在左下角画一个 `cell*0.105` 的"锐"字，缩略图上根本分不出来。

现在：

- 左下角一枚 **朱红方印**（`cell*0.235`，阴文白字，带硬阴影与内描边）
- 整牌一道朱边 `withAlpha(SEAL,.85)`
- 候选卡侧：`.lg-slot:has(em)` 朱色左缘 + 淡朱底

远看就能把精锐挑出来。

### 4.3 异兵融：独立演出 + 常驻融印

`isFusion(kind)` 认得三个融合兵（骁 / 戟 / 焰）。

**常驻标识**：左上角青金圆印「融」+ 顶缘青→金双色线（避开右上角的等级角标）。
它是两个兵种的孩子，牌面上就该带着"合过"的痕迹。

**演出**：`mergeUnits` 原来融合与普通升级共用一套冲击环，只换了飘字颜色。现在分三档：

- **异兵融**：交叉双锋（青 + 金两道 `slash`，法向相反）+ 双色冲击环（青大环 + 金小环）
  + 青火星 16 + 金碎块 18 + 22px「融 · 骁」飘字 + banner「异兵融 · 两笔成一兵」
- **五级**：金双环 + 金碎 24 + 金火星 14 + banner
- **普通升级**：单环 + 碎块 10 + **一道向上的短锋**（等级是往上走，方向感比光圈更直白）

三档都补 `unit.flash = 0.34`，主字闪一下品质色。

### 4.4 候选卡合成落定

点将台原来合完只是换了一个字，玩家不确定"到底合上没有"。

`combineBench` 记下 `benchPop` / `benchPopT`，`renderBench` 给那一格加 `is-pop`：
0.42s 先胀后压的回弹（`cubic-bezier(.22,1.4,.4,1)`）+ 0.5s 品质色扩散边框。
`prefers-reduced-motion` 下整段关掉。

## 七、遗留

- 宝箱掉率是按"中后期十几秒一只太密"判断下调的，作者没给具体目标值。
  实机跑下来若觉得偏紧，优先调定时间隔（110s），精英概率 0.25 是次要来源。
- 融合演出用掉了 `fx` 池里 2 个 slash + 2 个 shock 槽位。上限 `MAX_S=44 / MAX_SL=28`，
  同时连合多次不会溢出，但如果后续再加同类演出需要重新核算。
- 候选卡 `is-pop` 的类名靠 0.5s 时间窗自然失效；若期间没有新的 `syncBench`，
  类名会留在 DOM 上。动画是一次性的（无 `forwards` 残留态），不影响观感。
