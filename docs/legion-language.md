# 纸上军团 · 玩家语言规范与术语优化清单 v1

> 设计原则：**游戏可以有深度，但游戏语言必须简单。**
> 特色名称塑造世界观，通俗解释让玩家理解玩法，视觉反馈让玩家真正看懂规则。
> 每个功能都要回答三问：这是什么？有什么用？我用了会发生什么？数值必须明确。

## 一、语言规范

1. **特色名 + 通俗功能 + 具体效果**三段式。例：`笔势 · 阵型合击：3 名士兵连成一线，发动额外集体攻击`。
2. **双层命名**：
   - 有世界观价值的名（笔势/横锋/直锋/墨麒麟/抹笔/焚天/铁壁）→ 保留，首次出现给解释。
   - 纯功能名（招贤榜/点将台/重金纳贤/开疆/将台/炼兵）→ 主标题用直白词，原名降为小字副标题。
3. **数值明确**：伤害/攻速/范围/持续/目标数/是否对 Boss 生效/触发条件，不用模糊形容词。
4. **按钮说动作，状态说结果，错误说原因+差额**。
5. 氛围文字让位于功能说明；不写大段背景故事；不造生僻词。
6. **不改 id/key/存档字段/数值机制**，只改显示文案与新增引导/预览层。

## 三、新增体验层（本次实现）

- **新手引导**：预备期分步教练（部署→合击→合成→资源→成长），局部高亮+短提示，可跳过/在「玩法」里重看；进度存档（新增字段，向后兼容）。
- **部署预览**：拖拽时显示该格攻击覆盖的道路、可能连成的合击、周围联动变化。
- **合成预览**：拖拽叠合时浮出结果卡（等级/关键新能力/会断的合击/联动增减）。
- **合击可视**：墨线+成员+蓄力进度+压制态+伤害飘字。
- **动态建议**：基于真实状态在关键时刻给克制提示（成合击机会/合成会断阵/ coverage 缺口/工程师邻位/断笔者逼近），限频。
