# 工作室打磨轮 · 开局与结算（2026-11-25）

范围：十台机台的首页与机台外壳。不改玩法规则、不改关卡、不改存档键。
验收：`tsc --noEmit` 0 错、`vite build` 通过；桌面 1440×900 真实游玩走墨 / 垒塔 / 敲印 / 抽词 / 叠山 / 破砖，
手机 390×844 与 844×390（触屏）逐台开关；全程 console 0 报错，全部关机后 `window.__loops` 为空。

## 一、判断

上一轮把每台的玩法与可读性做扎实了，剩下的问题在"头"和"尾"：

- **开局没有第一眼。** 走墨 / 垒塔 / 敲印 / 抽词的开局是一张居中的小白卡（30px 标题 + 一句灰字 + 按钮），
  而且盖在一块**空画布**上 —— 改过窗口尺寸后 canvas 被清空，循环没起就没人重画，开机 30/300ms 的两次 refit 正好触发。
- **结算没有分量。** 判词 15px、印 46px，混在 HUD 中间，玩家打完一局看到的最后一眼比页脚提示大不了多少。
- **几处真 bug**（见下），都是"玩家会以为是卡了"的那一类。

## 二、修掉的 bug

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 叠山的向心聚合 / 印章 / 飘分落在页面最左边、台面之外 | `mgPlayMerge` 把台面内坐标直接交给 FX 层（FX 认视口坐标） | 加上台面 `getBoundingClientRect()` 左上角 |
| 破砖连击 ≥3 时球拖尾画在台面左上方之外 | `FX.trail(b.x, b.y)` 传的是 480×430 逻辑坐标 | 按画布矩形换算成视口坐标 |
| 走墨 / 垒塔 / 破砖开局或收场后改窗口，台面变白纸 | `fit` 改画布尺寸会清空，循环停着时无人重画 | `fit` 末尾补一帧静态画面（垒塔首次 refit 还没有塔，跳过） |
| 走墨背景每 960px 有一道竖坎（山脊与地面斜纹都对不上） | `sin(x·0.0042)` 与 22px 斜纹间距都不是画布宽的整数等分 | 山脊改成整幅内整数个起伏的谐波，斜纹间距取 `RW/40` |
| 纸上军团大厅按 Esc 没反应 | 大厅本身就是 `start` 覆盖层，Esc 走的是"关覆盖层"，等于什么都没做 | 大厅里的 Esc 交还机台厅关弹层；大厅上再开的子面板照旧先关自己 |
| 走墨 / 敲印 / 抽词开局面板按空格 / 回车没反应 | 走墨把空格当"起跳"直接 return；另两台没接键盘 | 开局面板盖着时空格 / 回车 = 开始 |

## 三、设计决策

### 开局面板 → 一张"开局海报"

四台共用一个版式：**编号 → 大字名 → 一句话（黄条）→ 纪录 → 通栏按钮 → 键位**，左对齐。

- 强调色按台分配，落在卡片硬阴影上：走墨朱砂、垒塔黄、抽词黄、敲印蓝。一眼能分出是哪一台。
- 面纱从 42% 调到 34%，台面里静止的场景（远山、塔基、十二格）透出来 —— 第一眼看到的是游戏世界，不是一个空框。
- 一句话玩法沿用首页 `.zone-note` 的黄条语汇，玩家在首页见过。
- 纪录行：有纪录写「最好 N 米」，没有就写「还没有纪录 · 这一局就是第一笔」—— 第一次打开也知道这局有什么可图。
- 标题族里的 Arial Black 不含汉字，中文落到雅黑是常规字重；所有海报上的黑体字补 `font-weight:900`。
- 触屏不显示键位提示；横屏手机上海报压扁（标题 32px、间距 7px），不把台面全盖住。

### 结算判词加大

判词 15 → 20px，印 46 → 58px。横屏手机上判词条是绝对定位压在台面底部的，那里保持 40px。

### 首页

- 应用卡中段约 90px 死白收掉（`34vh → 24vh` 下限），「小游戏」标题与第一行卡片进首屏。
- 末行只剩「敲印」一张、右边三个空格 → 铺成通栏横幅：名字 | 演示屏（十二格摆成 6×2）| 一句话 + ▶。
  演示屏同时改成 12 格，和游戏里的 4×3 对上（原来是 3×3 九格）。

### 破砖

- 七关的关名（入门实墙 / 双眼镂空 / 拱门 / 棋盘 / 三竖道 / 堡垒 / 终局）原来只写在代码注释里，
  现在每关开场盖一枚印章，停 1.3s 再淡出（`FX.stamp` 新增可选 `hold`，不传时行为不变）。
- 普通砖按行分深浅（顶行深、底行浅，明暗差约 14%）。一整面 104 块同一个蓝读起来是一块色板。

## 四、验证

- 空格 / 回车开局：走墨、垒塔、敲印、抽词均 `true`。
- 军团大厅 Esc：弹层 `is-on` 变 `false`。
- 叠山合并特效、破砖拖尾：截图里都落在台面内。
- 走墨跑到 32 米：山脊、地面斜纹连续，无接缝。
- 破砖印章：1s 时在、2.5s 后收。

## 五、还可以继续的

- 抽词开局时牌还没铺，背景是空网格；可以先铺牌背再盖面板，和另三台一样"看得见台面"。
- 敲印开局后面板后面是十二个空格，可以放两三枚定格的印当背景。
- 稿纸、砖块、叠山没有开局面板（开机即玩），是否需要一张统一的"第一次打开"说明，要看真实首玩数据再定。
- 纸上军团本轮只动了 Esc 一行，大厅与战斗内的版式未审。
