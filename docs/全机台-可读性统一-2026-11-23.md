## 2. 统一口径（与墨潮同一套）

### 2.1 层级三分

```
标签（12–13.5px，灰 #6b6255，字距 .1em）
  └ 数值（×1.75 ≈ 21–23.6px，墨黑 #252525）
      └ 分数 / 连击（×2.05 ≈ 25–27.7px，朱砂 / 金）
```

- 分数前加 1.5px 竖分隔线，与“关卡、剩余”等状态分开；
- 连击默认压到 50% 不透明度，`is-on` / 有连击时才提到 100%；
- 主题（三国 / 山水）从裸文字改成带墨边的小印章，6px 圆点 + 8px 内边距。

### 2.2 页脚：键帽 + 动作

页脚会随局面改写（“还剩 18 组 · 槽里 0 张”），所以没有逐条替换文案，而是在 `engine.ts` 里给 `#mHint` 挂了一个 `MutationObserver`：

- 文本变化时把 `WASD / Enter / Esc / Q / P / 空格 / 方向键 / 拖动 / 回车 / 1-3` 包成 `<b>` 键帽；
- `·` 换成 `<i>` 分隔点，留白从 0 变成左右各 6px；
- 只改 `innerHTML` 的包装，文本本身一字不动（读屏、复制、逻辑判断都不受影响）；
- 观察器里用“上次渲染的纯文本”做幂等保护，不会自触发死循环；`cleanup()` 里 `disconnect()`。

字号 11.5–13px（随视口），键帽 1.5px 墨边 + 2px 实阴影，与墨潮页脚同一款。

### 2.3 顶栏与纸面

- `.m-no` 10.5px / `.m-name` clamp(15,1.35vw,19) / `.m-tag` 11px 带边框；
- 稿纸、专注：`.sheet-head/.sheet-foot` 10.5px，`.ro-meta` 11px，`.source` 11px（专注深色面板单独提到 80% 不透明度）；
- 抽词：`.pfront .pn` 11px，成双印 10px。

### 2.4 状态与键盘

- 所有台面控件（砖、牌、格、HUD 按钮、开始按钮、关闭、再来一次）补同一条 `:focus-visible` 焦点环：3px 朱砂、offset 3px；
- 没有新增缩放/弹跳：hover 仍是原有的位移与阴影，焦点只用描边表达。

## 6. 遗留

1. **纸上军团**（`legion/`）仍在并行开发，最后改动距发布约 20 分钟；它有自己的 canvas UI 与 `legion.css`，右侧招募栏还有 9–10px 的小字与待校文案。这轮没有动它，避免和进行中的改动互相覆盖；它的 UI 应单独一轮收口。
2. 页脚只统一了字号与键帽，没有逐台重写文案；个别状态句仍然偏长（如破砖“点一下发球（接球的位置决定角度）”）。
3. 装饰性小字仍是 7–10px（如抽词牌角纹样、敲印的印面细节），不承载信息，未放大。
4. 手机端横屏/竖屏布局未改（统一层只在 `min-width:901px` 生效），触屏页脚仍用原尺寸。
5. 页脚观察器只认固定的键位词表；以后新增键位（如手柄映射）需要往正则里补词。
