## 1. 军团：这次改了什么

### 1.1 字号：把 <12px 的“注脚”抬成可读层

开工前扫了一遍 `legion.css`：154 处 <12px 声明、40 个选择器在 12px 以下，集中在三处——顶栏标签（10px）、卡片角标（8–10px）、右栏说明（8–9px）。处理方式和十一台统一层一致：**不整体缩放，只抬标签层**，数值与标题保持原比例。

| 位置 | 改前 | 改后 |
| --- | --- | --- |
| 波次/下一波/营寨标签 | 10–10.5px | 11.5px；营寨数值 15px |
| 资源（粮/银/敌/斩） | 9–11px | 标签 11px、数值 16px |
| 卡名 | 10–12px | 桌面 12.5–13px、手机 12.5px |
| 稀有度签 | 8–9px | 10.5px |
| 兵种定位 | 8px | 11px |
| 招募价 | 9px | 12px |
| 刷新/重金纳贤/连招 | 8–9px | 11.5px |
| 选中单位正文 | 8–9px | 11.5px / 行高 1.65 |
| 战术/道具/点将台说明 | 8–9px | 11–11.5px |
| 遣散提示 | 9px | 11px |
| 右侧区块标题数字 | 8px | 12px |

判定标准：**承载信息的字 ≥11px，装饰性字 ≥10px**；保留的 10.5px 只有技能键帽“Q”和品质签。

### 1.2 手机竖屏（≤940px，390×844 实测）

沿用原有“底部抽屉”结构，只做三件补强：

1. `.lg-round` 26→34px、`.lg-skill` 28→34px，触屏能点中；技能名 11.5px；
2. 招募面板与选中单位 `max-width:none`，配合 `.lg-dock{align-items:stretch}`，卡片从 52px 宽撑到 ~118px（三列铺满 374px），大字不再挤在两行里；
3. 首屏（开始层）隐藏装饰格与英雄卡，标题 36px，页面顶部对齐——`开始守卫` 键落在第一屏内，不用先滑半屏。

页脚提示换成触屏语义：`拖卡 下阵 · 同名同级 叠放 · 点棋子看专精`（14 字，一行放下，原键盘版 30 字会折两行贴边）。

### 1.3 手机横屏（≤940px 且高 ≤560px，844×390 实测）

原来底部抽屉固定 306px 高，390 高的屏只剩一条缝。这次改成**右侧栏**：

- `.lg-dock`：`top:50px; right:0; bottom:0; width:min(310px,38vw)`，纵向滚动；棋盘区 534×340；
- `.lg-top` 压成单行 50px：波次、整备、营寨（`flex:0 1 160px`、数字 13px 不换行）、资源、工具、关闭；
- 隐藏 `.lg-stage`、隐藏机台页脚（`.modal[data-game=legion] .machine-foot`），否则大厅的「再来一次」会浮到左上压住波次；
- 顶栏 `padding-right:46px` 给关闭键让位；卡片 3 列 82px、兵种定位隐藏；点将台 4 列 44px。

### 1.4 代码层：dock 方向不再靠猜

`legion/game.ts` 的 `resize()` 原来按“是不是手机”推 dock 方向，横屏时把底部抽屉当成右栏算，棋盘被算成一条缝。现在按实测几何判断：

```ts
const dockRight = m.dockW > 0 && m.dockW < w * 0.7;
const dockW = dockRight ? m.dockW : 0;
const dockH = dockRight ? 0 : m.dockH;
```

桌面右栏、竖屏底抽屉、横屏右栏三种形态共用一套算式，不再各自特判。

## 2. 墨潮：陨石分散落点

`METEOR`（id `meteor`，进化「天坠」六块连坠）原实现只取一个中心点，每块加 `±70` 抖动，六块基本叠在同一只敌人身上，旁边一群没人管。

改成“一块石头认一只敌人”：

1. `enemiesNear(px, py, 720)` 取候选，Fisher–Yates 打散；
2. 贪心挑选彼此间距 ≥ `0.6R`（`R = size × area`）的目标，最多 `count` 个；
3. 敌人不够时，围绕已选点重心（无敌人则玩家附近）按黄金角 2.399 铺环，半径 `0.72R` 起，一圈放不下自动外扩；
4. 每块错开 60ms 落地，形成连坠；
5. 进化收尾以重心放一圈震波，半径 `max(1.25R, 最远落点 + 0.7R)`，兜住整片落点。

文案同步改为“天上落一串墨石，每块分头找一只敌人砸”。
