## 一、游戏卡标题两套对齐（桌面 + 手机）

`.cab-top` 用 `justify-content:space-between`，三个子元素是「编号 / 名字 / 横屏角标」。
带角标的 3 张卡（纸上军团 / 墨潮 / 走墨）名字靠左；**没有角标的 7 张卡名字被推到右端**，
同一面目录墙上一半左对齐一半右对齐，读起来像排版事故。

处理：`.cab-top` 改 `justify-content:flex-start`（桌面基规则与 ≤900 断点各一处）。
角标自己已有 `margin-left:auto`，靠右不受影响；末行敲印通栏横幅的 `.cab-top`
是独立的 column 规则（优先级更高），不受牵连。

验证：1440 下九张网格卡名字左缘距卡顶左缘统一 22px（改前 7 张为右对齐）；
390 下目视一致。见留档图 `docs/img/目录卡对齐-2026-11-27.png`。

## 二、手机机台顶栏：名字折成两行、角标折成两行

390×844 开纸上军团：顶栏「纸上军团」折成「纸上军 / 团」，黄色角标折成
「无尽守卫 · 招募 · 合成 · 自动战 / 斗」，顶栏被撑到两行高。
原因：`.m-name` / `.m-tag` 没有 `white-space` 与 flex 约束，≤420 空间不够时
flex 把两者一起压缩换行。

处理（hall.css 末尾「机台外壳」段）：

- `.m-name{flex:none;white-space:nowrap}` —— 台名是身份，不缩不换行；
- `.m-tag{flex:0 1 auto;min-width:0;overflow:hidden;white-space:nowrap;text-overflow:ellipsis}`
  —— 角标是补充信息，放不下省略号（玩法在开局面板里还写了一遍）。

验证：390 下名字单行 20px、角标单行 18px、顶栏 48px；截断显示「…自动战…」。
桌面与 901–1100 笔记本不受影响（角标原本就放得下）。
