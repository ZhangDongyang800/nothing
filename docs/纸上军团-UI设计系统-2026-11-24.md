## 0. 这份文档怎么用

1. **单一事实源**。颜色、字号、间距、边框、圆角、阴影、尺寸、动效、层级，只允许从 `design/tokens.css` 取（canvas 端从 `design/tokens.ts` 取）。任何新写的 CSS 里出现 `#hex`、`rgba()`、`font-size: 17px`、`border-radius: 6px` 一律视为 defect，不看理由。
2. **优先级**。本文件 > 旧 `legion.css` / `legion-v6.css` / `legion-v7.css`。旧文件在迁移期仍生效，但**不允许再往里加规则**（见实施计划 P0）。
3. **一次只改一屏**。设计系统落地按屏替换，不按组件批量替换——因为一个组件的"对"与"错"取决于它在哪一屏的密度里。
4. **不许发明**。需要新组件时，先在本文件"组件体系"里补一行规格，写清尺寸/状态/使用场景，再写代码。跳过这一步的新组件视为"无设计依据"。

## 1. 设计原理（从参考作品里提取的，不是照搬外观）

| 参考 | 提取的是 | 在本作的落地 |
| --- | --- | --- |
| Slay the Spire | 信息密度可以很高，但**层级必须靠"位置 + 字号 + 颜色"三重固定**，不能靠装饰区分 | 一场战斗的信息全部塞进"顶栏 56px + 棋盘 + 棋盘下 72px 读数条 + 右栏 384px"，不弹窗、不折叠 |
| Into the Breach | 棋盘是**唯一主角**，其它面板是它的注解；战术信息贴在格子上而不是另开面板 | 笔势画在格子里（`is-stroke-h/v`）、Boss 条与棋盘同宽、读数条在棋盘正下方 |
| Hades | 图标只有**两套语言**，且每套有严格的网格与线宽；材质统一，不混 | 字印（汉字=兵）+ 线符（24 网格 / 1.5px）两套，禁止 emoji、禁止彩色图标 |
| 传统兵书 / 桌游 | 纸、墨、朱砂三色足够；留白是结构，不是待填的空 | 5 级纸 + 4 级墨 + 1 个朱砂；面板不叠卡片底，靠线与留白分区 |

三条本作自定的判定标准（任何设计决策都要能回答）：

1. **这条信息玩家在 0.5 秒内需要吗？** 需要 → 常驻、进首屏、用 13px 以上；不需要 → 进弹层或折叠，不许挤在首屏。
2. **这块颜色/线条在表达什么？** 说不出"它表示什么状态"的，删掉。
3. **这个元素占的像素，值它的信息量吗？** 一个 96×96 的格子只放一个字形是值的；一个 240px 高的面板只放两行字不值。

## 2. 视觉语言

### 2.1 核心风格

**纸上兵书 · 墨线朱砂**。三句话：

- **底是纸**：从 `#f6eedc` 到 `#d8c79f` 五级，靠纸色深浅分区，不靠投影和卡片底。
- **字是墨**：正文 `#23201a`，越次要越淡，淡到 `#b6ab93` 为止（不再有 40% 透明度的"灰字"）。
- **重音是朱砂**：`#a8342a` 只表示三件事——危险（敌方/掉血）、战斗（正在打）、强调（当前选中的那一个）。

金 `#b8860b` 只表示"最好/最高/传说"。青、靛、紫只出现在品质与状态语义里，不做装饰。

### 2.2 色板

| --- | --- | --- | --- | --- |

| 纸面 | `--lg-paper-1` | `#fbf6e8` | 卡面、面板、按钮底 | 大面积铺（会跟页面底打架） |

**品质色**（`--lg-rar-common/fine/rare/epic/legend` = `#6b6255 / #3f6b3a / #33628f / #6b4a8f / #b8860b`）必须与 `data/rarity.ts` 的 `RARITY_COLOR` 完全一致；改一处必须改另一处，`qa-design-lint` 会比对两个文件。

**对比度底线**：承载信息的文字 ≥ 11px 且对比 ≥ 4.5:1（纸底上的 `--lg-ink-2` 刚好过线，`--lg-ink-3` 只许用于非信息文本）。金底上的字用 `--lg-ink-0`（`#fbf6e8` on `#b8860b` 只有 2.8:1，不许）。

### 2.3 字体

| 字体栈 | Token | 用途 | 硬规则 |
| --- | --- | --- | --- |
| 宋（display） | `--lg-font-display` | 标题、判词印、大数字、单位字形 | **只用于 ≥ 22px**。22px 以下的宋体在 Windows 上会糊 |
| 黑（ui） | `--lg-font-ui` | 正文、按钮、标签、表格 | 默认字体 |
| 等宽 | `--lg-font-mono` | 坐标（A–F / 1–7）、键帽、纯数字对照 | 数字必须 `tabular-nums` |

### 2.4 字号阶梯（九个角色级：八级文字 + 一档数字）

| 级 | Token | 值 | 用途 | 行高 |
| --- | --- | --- | --- | --- |
| display | `--lg-fs-display` | `clamp(34px, 3vw, 44px)` | 页面主标题 | 1.15 |
| h1 | `--lg-fs-h1` | 28px | 弹层标题、屏内一级 | 1.15 |
| **num** | `--lg-fs-num` | 24px | **只有数码**（战绩、总额、结算数字），不用于文字 | 1.25 |
| h2 | `--lg-fs-h2` | 20px | 区块标题、卡片名（宋体需 1.25 行盒才不被自身 overflow 切） | 1.35 |
| body-lg | `--lg-fs-body-lg` | 15px | 说明段、强调正文 | 1.6 |
| body | `--lg-fs-body` | 13px | 正文 | 1.6 |
| label | `--lg-fs-label` | 12px | 按钮、表头、标签 | 1.35 |
| caption | `--lg-fs-caption` | 11px | 角标、注释（**承载信息的下限**） | 1.35 |
| micro | `--lg-fs-micro` | 10px | 仅装饰刻度或已有 aria 复述 | 1.35 |

`num` 是唯一允许"同一语义在同一屏用两种字号"的例外：文字用 h2 / body，数字用 num，因为数字要竖排对齐（`tabular-nums`）且读数比句子快。除此之外**没有第十级**，也不允许以 `calc()` 从别的级推导新字号（槽位字印是唯一例外，见 3.2）。

上一轮《可读性与手机适配》定的"承载信息的字 ≥ 11px、装饰字 ≥ 10px"继续有效，本表是它的工程化版本。**任何页面不允许出现 9px / 8px / 7px**（旧 CSS 里有 234 处 ≤10px 声明，属于迁移债）。

### 2.5 边框、线、阴影

| 类 | Token | 值 | 用在哪 |
| --- | --- | --- | --- |
| 发丝线 | `--lg-rule-1` / `--lg-b-hair` | `rgba(35,32,26,.16)` / 1px | 行分隔、格线、表内分区 |
| 结构线 | `--lg-rule-2` / `--lg-b-rule` | `.32` / 2px | 面板内外框、按钮、卡片 |
| 强线 | `--lg-rule-3` / `--lg-b-frame` | `.64` / 3px | 棋盘外框、弹层外框（全屏最多两处） |
| 硬影 1 | `--lg-shadow-1` | `2px 2px 0 rgba(35,32,26,.14)` | 可拖拽物、主按钮 |
| 硬影 2 | `--lg-shadow-2` | `4px 4px 0 rgba(35,32,26,.18)` | 弹层 |
| 选中环 | `--lg-ring` | `0 0 0 2px #a8342a` | 唯一的"选中"语法 |

**没有模糊阴影，没有内阴影（除单位字的 1px 反白描边），没有双层投影。**

### 2.6 材质

- **纸纹**：`24px` 点阵、透明度 3%，只在 `.ds-screen` 底上出现一次。不叠第二层，不加大理石/纤维噪声图。
- **墨块**：我方单位 = `--lg-ink-0` 实底 + 纸色字 + 1px 反白内描边（保证在深格上还能看出边界）。
- **朱砂印**：`ds-seal--stamp` 是唯一允许的"实心色块 + 白字"，一屏最多一枚（标题印或判词印）。
- **装饰边界**：允许的装饰只有四种——①棋盘四角套准线（14px，纸色，只在棋盘出现一次）；②分节头的 3×12px 朱砂竖标；③笔势虚线；④序号（壹贰叁肆）。除此之外的图案、纹样、斜纹底、渐变全部禁止。

## 3. 空间布局

### 3.1 一条总原则

**棋盘优先，其余让位。** 任何布局冲突时，先保棋盘的尺寸与可见性，再砍面板、再折叠、最后才缩字号（缩字号是最后手段且不得低于 11px）。

### 3.2 战斗屏区域划分（≥1440）

```
┌──────────────────────── 顶栏 56px（单行，内容压缩不重排）────────────────────────┐
│ 波次 · 阶段 · 营寨血条(≤300) · 粮/银 · 笔势 · ┄┄┄ 工具组（右对齐）             │
├──────────┬──────────────────────────────────────────┬──────────────────────────────┤
│ 战术栏    │           棋盘列（棋盘定宽居中）           │        行动栏 384px          │
│ 208px    │  Boss 题签 = 棋盘同宽（36px）             │  招贤榜（3×112 卡 + 按钮）    │
│ 只读     │  棋盘 6:7（宽度由可用高度反推）             │  点将台（4×72 格）            │
│          │  读数条 72px（选中单位的唯一详情位）        │  道具（40 方 + 计数）         │
├──────────┴──────────────────────────────────────────┴──────────────────────────────┤
```

- **左栏 = 只读战况**（战场、敌情、笔势、战术构筑、下个 Boss）。它没有按钮，只显示"现在是什么状况"。
- **右栏 = 可做之事**（招贤、点将、道具）。所有可点的东西在右栏，所有读数在左栏与棋盘。
- 两栏都**没有卡片外框**，只有一条竖分隔线（`--lg-rule-1`）。面板靠"分节头 + 留白"分区，不靠卡片堆叠。
- **右栏最后一段（道具）钉在栏底**（`margin-top:auto`）。上方是"本波要做的决策"，下方是"随时要用的一次性库存"——按使用频率分开，中间的空档因此是刻意留白，而不是没填满的洞。

### 3.2b 标题屏（起始页 / 择将）的垂直组成

标题屏不套用战斗屏的三栏，但必须遵守"一屏一个主角 + 两端锚定"：

- 左栏从上到下：Kicker → 题目（印 + 主标题）→ 一句定位 → **四拍步骤表** → 战绩（钉底）。
- 四拍必须是**纵向步骤表**（序号 壹贰叁肆 + 步骤名 + 一句解释），不是四个等价胶囊。理由：招募→合兵→布阵→守 是**有先后**的流程，四个等宽标签会把它读成四个并列功能。
- 战绩用 `margin-top:auto` 钉在页脚上方，与"上一局"同一条基线：这一屏的上下两端各有锚，中段的空白才是构图，不是漏洞。
- 右栏从上到下：本局地图（唯一大图）→ 主行动（`primary lg`）→ 次行动 → 弱入口 → 一句脚注。主行动永远是右栏第一颗按钮。

### 3.3 面板尺寸规范

| 元素 | 尺寸 | 依据 |
| --- | --- | --- |
| 顶栏 | 高 56px | 一行容得下 7 组信息；波次用 h1（28px 宋），与 56 的框高形成"字占框一半"的紧凑感，不撑高顶栏 |
| 左栏 | 208px（≥1440 才出现） | 13px 正文 180px 行宽约 13 字，够放短句；低于 1440 直接隐藏，不缩 |
| 右栏 | 384px（1440+）/ 320px（1100–1439） | 3×112 + 2×8 + 32 = 384，整除，不留半格 |
| 招贤卡 | 112×136 | 四段固定：带 18 / 主体 ≥56 / 定位 32 / 价 28 |
| 点将格 | 72×72（触屏 64） | 与棋盘单格视觉等比 |
| 棋盘下读数条 | 高 72px，与棋盘同宽 | 常驻，避免选中时棋盘跳动 |
| Boss 题签 | 高 36px，与棋盘同宽 | 不浮动、不遮格 |
| 弹层 | 480 / 720 / 960 | 三档，按"内容是否需要并排两列"选 |

### 3.4 断点（只有四档）

| 断点 | 布局 | 棋盘 | 右栏 | 左栏 |
| --- | --- | --- | --- | --- |
| ≥1440 | 三列 208 / 1fr / 384 | `min(100%, (100vh−228px)×6/7)` | 384 | 显示 |
| 1100–1439 | 两列 1fr / 320 | 同上 | 320 | 隐藏 |
| 900–1099 | 两列 1fr / 320，卡片不缩字号 | 同上 | 320 | 隐藏 |
| <900（竖屏） | 单列：顶栏 / 棋盘 / 读数条 / 抽屉 | 300 定宽（6×50） | 抽屉，可滚 | 收起进抽屉 |
| 横屏触屏（h≤560） | 1fr / 300 | 高度反推 | 300 固定 | 隐藏 |

竖屏细则（必须照做，这是上一轮"296px 抽屉"结论的修订版）：

- 顶栏三行：波次+阶段+资源 / 营寨 / 笔势+工具。**用 `order` 调序，不改 DOM**。
- 棋盘 300 宽（格 50，仍高于 44 触控下限），不为塞内容而缩到 250 以下。
- 读数条两行：上行 字印+名+笔势标签，下行四个读数。**不许把四个读数硬挤一行**（会把"攻击"折成两行）。
- 抽屉（右栏）独占剩余高度、内部滚动，只保留两个页签（招贤 / 点将），道具作为第三个页签折叠。
- 首屏必须同时看见：顶栏、棋盘、当前选中读数、招贤三张卡。买不起时按钮禁用而不是隐藏。

### 3.5 首屏与滚动规则

1. **首屏完整性**：进入任一界面，不滚动就要能看见"当前状态 + 主行动"。战斗屏 = 棋盘 + 读数 + 招贤；起始屏 = 标题 + 开始/继续；结算 = 波次结论 + 再来一局。
2. **允许滚动的只有**：左栏（内容长）、抽屉（手机）、弹层正文。棋盘、顶栏、读数条、主按钮**永不滚动**。
3. **禁止默认纵向堆叠**。任何"六段从上往下排"的面板都算 defect——先问"这六段里哪三段应该在左栏/抽屉页签里"。

## 4. 图标体系

### 4.1 两套语言，不许混

| | 字印（Seal） | 线符（Line） |
| --- | --- | --- |
| 表达 | **实体**：兵种、英雄、道具、强化、品质 | **动作/状态**：暂停、倍速、设置、关闭、静音、刷新、锁定 |
| 构成 | 汉字 + 方框（2px 墨线，直角） | 24×24 网格，1.5px 描边，方头，`fill: none` |
| 字号 | 框宽 × 0.62 | 线宽固定 1.5，不随尺寸变 |
| 尺寸 | xs 22 / sm 28 / md 44 / lg 64 / xl 88 | sm 16 / md 24 / lg 32 |
| 颜色 | 墨（纸字）或反白；品质由左缘 3px 条表达 | 单色 `currentColor`，只允许墨或朱砂 |

`design/icons.ts` 是唯一注册表：`SEAL_SPEC` 定义字印规格，`LINE` 收录 16 个线符（`pause/play/fast/settings/close/sound/mute/reroll/trash/lock/plus/check/chevron/info/target/flag`）。新增线符必须先加进 `LINE` 并写 `LINE_LABEL`。

### 4.2 分类与语义

| 类 | 载体 | 例 |
| --- | --- | --- |
| 兵种 | 字印 | 刀 枪 弓 骑 法 工 术 骁 戟 焰 |
| 英雄 | 字印（加朱砂左缘 = 已出战） | 锋 鸢 鹭 雪 |
| 资源 | 字印 `xs` 22px（粮 银 金 材 碎） |
| 道具 | 字印 | 征 药 |
| 强化 | 字印（无框，纯字） | 锋 田 城 |
| 界面动词 | 线符 | 见上 |
| 状态 | **不用图标** | 用颜色 + 位置：选中=朱砂环，禁用=降墨，冷却=底部进度条 |

**语义硬规则**：一个图标只能有一个意思。`flag` 不许同时表示"目标"和"标记"；`lock` 只表示"锁定"，不表示"未解锁"（未解锁用降墨 + 计数）。

### 4.3 状态表现（四态，不许加第五态）

| 状态 | 字印 | 线符 | 说明 |
| --- | --- | --- | --- |
| 默认 | 纸底墨框墨字 | 墨色 1.5px | |
| 选中/当前 | 墨底纸字（`is-on`） | 朱砂 | 全屏只允许一个"当前" |
| 禁用 | 纸-2 底、`ink-3` 字、`rule-2` 框 | 同左，`opacity` 不降 | **不许用 opacity 表示禁用**（会和"锁定"混） |
| 冷却 | 底部 3px 朱砂进度条（从右往左退） | — | 时间用条形，不用数字 |

### 4.4 图标背景与装饰

- 字印自带方框，**不再加圆角、不加投影、不加双层框**。
- 线符**永远不加背景块**（按钮底是按钮的事，不是图标的）。
- 禁止：emoji、彩色图标、SVG 渐变、图标内文字描边、图标 + 文字重复（"弓"字印旁边再写"弓兵"属于重复，需要时二选一）。

## 5. 组件体系

所有新组件使用 `ds-` 前缀（旧现役组件是 `lg-`），样式集中在 `design/components.css`。下表是每个组件的**规格 + 状态 + 使用场景**，也是后续 AI 写代码时的对照表。

### 5.1 按钮 `.ds-btn`

| 变体 | 高度 | 内距 | 边框 | 用途 | 一屏上限 |
| --- | --- | --- | --- | --- | --- |
| `--primary` | 36 / lg 48 | 16 | 2px 墨 + 硬影 1 | 一屏唯一的主行动（开始守卫、再来一局） | 1 |
| 默认 | 36 | 16 | 2px 墨 | 次级主行动（继续上局） | 2 |
| `--quiet` | 36 / sm 28 | 16 / 12 | 1px `rule-2` | 次要动作（刷新、局外成长） | 3 |
| `--accent` | sm 28 | 12 | 1px 朱砂 + 朱砂字 | 花钱/用命的动词（重金纳贤、铁壁） | 2 |
| `--link` | 28 | 0 | 无，常驻下划线 | 文字动词（连招、查看玩法） | 3 |
| `--ghost` | 28 | 4 | 无 | 页脚入口（玩法、设置、回目录） | 3 |
| `--icon` | 28 / 36 | 0 | 同所在变体 | 只有线符的方按钮 | 不限 |

- 小按钮（`--sm`，28px）**边框一律 1px**：2px 在 28px 高上会读成"重按钮"。
- 状态：hover 提亮纸面（`#fff`）/ accent 加 6% 朱砂底；active `translate(1px,1px)` 并去影；disabled `paper-2` 底 + `ink-3` 字 + `not-allowed`。
- 禁止：渐变按钮、圆角 > 2px、带图标的文字按钮做装饰性图标。

### 5.2 招贤卡 `.ds-card`

固定四段（`18 / 1fr / 32 / 28`，总高 136）：

| 段 | 内容 | 规格 |
| --- | --- | --- |
| 带 | 品质词 + 定位短语 | 18px，品质底色，纸色字；传说用墨字 |
| 主体 | 28 字印 + 名（20px 宋体，**行高 1.25**，单行省略） | 名最多 2 字（112 卡身：88 内宽 − 28 印 − 12 间距 = 48px，2 字刚好）；3 字以上必然省略，因此不许给卡片起 3 字名 |
| 定位 | 一句玩法定位 | 11px，最多两行，超出截断 |
| 价 | `粮 9` + 合成提示 | 价 13px 粗，资源字 11px 灰；`可合` 用 `ink-2`，`差一 成阵` 用 `.is-hot` 朱砂 |

状态：hover 上浮 1px + 硬影 1；disabled（买不起）`opacity .45` + 不可点。**品质只在顶部带出现一次**，卡上不再有第二处品质色。

### 5.3 点将格 `.ds-slot` / 道具 `.ds-item`

- 格 72×72（触屏 64），内含 30px 字印 + 底部等级点；有货时左缘 3px 品质条，空格时虚线框 + `＋`（`#b6ab93`）。
- 拖拽目标态：虚线变成朱砂实线 + `+n` 预判徽标（合兵 n=1，融合 n=0.5）。
- 道具 = 40×40 方 + 右下角计数（11px）。

### 5.4 面板与表格

| 组件 | 用途 | 规格 |
| --- | --- | --- |
| `.ds-sec-head` | 所有分节头 | 高 28 + 3×12 朱砂竖标 + 11/12px 标题 + 右对齐说明（11px）。**全站唯一的分节语法**，不许再用"卡片标题栏" |
| `.ds-stats` | 4 列键值（生命/攻击/护甲/射程） | 上下发丝线，列间发丝线，label 11px 灰 / value 15px 粗 |
| `.ds-ledger` | 本局/最佳对照（结算） | 三列 `1fr auto 64px`，行高 32，发丝线分隔 |
| `.ds-readout` | 棋盘下选中单位 | 36 字印 + 名/meta + 4 读数 + 笔势标签；72px 常驻 |
| `.ds-record` | 大数字（最高波次） | label 11px + 值 `--lg-fs-num` 24px 宋体 tabular |

### 5.5 弹层 `.ds-modal`

- 三档宽度 480 / 720 / 960；`max-height: 88vh`；外框 3px 墨 + 硬影 2；圆角 4px（全站唯一允许 4px 的地方）。
- 结构固定：`head 56px`（kicker 11 + 标题 28 + 右侧关闭）/ `body`（唯一可滚区）/ `foot 64px`（主行动在左，次要在右）。
- 遮罩 `rgba(28,25,20,.55)`，不做模糊。

### 5.6 状态标签 `.ds-chip`

11px、1px 框、内距 4×8、圆角 2。语义变体只有：默认（墨框墨字）/ `is-seal`（朱砂）/ `is-gold`（金）/ `is-off`（灰虚线，表示"还有 N 个没显示"）。**不许做圆角胶囊、不许加图标。**

## 6. 交互规范

| 交互 | 规则 | 反馈 |
| --- | --- | --- |
| hover | 只改两样：纸面提亮一档 / 出现硬影 1 | ≤80ms，**不做缩放** |
| 选中 | 朱砂 2px 环（`.ds-ring`）或字印反底 | 立即，无过渡 |
| 拖拽 | 起点浮起：硬影 1 + 旋转 -1.5°（≤240ms）；落点合法时目标格虚线转朱砂实线并显示合/融的 `+n` | 拖动中棋盘其它元素不动 |
| 点击 | `translate(1px,1px)` + 去影 | 80ms |
| 禁用 | 降墨 + `not-allowed`，**不弹提示**（原因写在旁边，不写 toast） | 无 |
| 战斗反馈 | 伤害 = 单位抖动 2px + 数字上浮 24px 淡出（240ms）；掉血 = 血条 1 帧内更新 | 不用粒子、不用屏幕闪白 |
| 动效 | 只有 80/160/240 三档 + 两条曲线（`--lg-ease-out` / `--lg-ease-in-out`） | `prefers-reduced-motion` 下时长归 1ms，只留透明度 |
| 触屏 | 命中区 ≥44（`--lg-tap`）；长按 400ms = 详情，短按 = 选中；**不依赖 hover 表达任何信息** | 触屏版本所有 hover 语义必须有常驻替代 |

## 7. 反设计清单（出现即 defect）

1. 无意义的装饰性图标（齿轮、星光、锁链只为"好看"）。
2. 每个区域都套独立卡片背景（本作只有 4 种真实容器：棋盘、弹层、卡片、槽位）。
3. 圆角超过 4px；同一屏出现 3 种以上圆角。
4. 模糊阴影、双层阴影、内阴影（单位反白描边除外）。
5. 渐变（进度条、按钮、背景一律禁止；唯一例外是过渡遮罩）。
6. 两套图标风格混用（字印旁出现彩色线性图标）。
7. 为填充空间添加装饰（补角线、花边、多余分隔线、空状态插图）。
8. 靠缩小内容解决布局（把 11px 缩到 9px 塞进面板）。
9. 未经分析随意新增 UI 元素（"顺手加个迷你地图"）。
10. 同一信息在两处重复（结算左栏与台账同时列"斩敌"）。
11. 用 opacity 表达禁用（与"锁定/未解锁"混淆）。
12. 裸字面量：`#hex`、`rgba()`、非阶梯字号、非许可圆角/阴影。
13. `!important`（除 `.ds-screen` 内部的 `box-sizing` 兜底）。
14. 纵向堆叠式布局当作默认解（六段从上往下排）。
15. 首屏放不下就把主按钮藏起来，或把主按钮做成"看起来像注释"的文字。

## 9. 变更流程

1. 想加/改组件 → 先改本文件对应小节（写清规格与理由）。
2. 改 token → 同步 `tokens.ts`；品质色还要同步 `data/rarity.ts`。
3. 写代码 → 只用 `var(--lg-*)`；新页面用 `ds-*`。
4. 提交前 → `node site/scripts/qa-design-lint.mjs` 必须 0 error；视觉改动附一张对照截图（`.qa/keep/` 只留一张）。
5. 每完成一屏 → 在本文件末尾"已迁移"清单里打勾，避免同一屏被两代人写两遍。
