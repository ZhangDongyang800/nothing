## 一、作者反馈：底部那条页脚没有必要单独存在

原话：游玩时每个游戏底部都有一条「↻ 再来一次 · 拖卡下阵 · 同名合 · 异兵融 · Q 英雄技 · 空格暂停 · 1-3 招兵 · 01/10」，
没有必要、会遮挡，要求融合到其他位置。

那条是机台外壳的 `.machine-foot`，高 46–56px，十台共用。它的问题不只是占地方：

- 它和顶栏是同一类东西（都是"这台是什么、怎么操作、怎么退出"），却分居屏幕两端，眼睛要来回跑。
- 台面（`.pane`）被它吃掉一条高度。砖块 / 叠山 / 破砖这类"盘子吃满高度"的机台，少的就是盘子。
- 右下角的 `01/10` 与左上角的编号重复了一遍。

处理：**整条删掉，内容原样搬进顶栏右侧**。

- `Hall.tsx`：删除 `.machine-foot` 容器，把 `mHint / mReplay / mSeal / mClear / mCount / m-close` 搬进 `.machine-top` 新增的 `.m-tools`。
  **元素 id 全部保留**，各台写 `MHINT` / `MREPLAY` 的代码一行没改。
- `mCount` 保留但隐藏（engine 仍在写它，删元素会 NPE）；左上角编号改用 `info.idx`，显示成 `01 / 10`。
- `hall.css`：删掉 `.machine-foot` 的基规则与 ≤900 / ≤420 / 横屏三处引用，末尾新增「机台外壳」一段。
  横屏原来把页脚浮在左上角，现在动作按钮跟着顶栏一起到右上角。
- 提示（`.m-hint`）单行省略；≤900 收起（触屏没有键盘，规则在开局面板与顶栏标签里已经写过）。
  901–1100 的笔记本仍然保留提示 —— 放不下时自己省略号，总比整条消失强。

收益：**每台台面多出 46–56px 高度**。桌面 1440×900 下 `.pane` 从 802 涨到 848。

## 二、补审：此前没审过的东西

### 02 墨潮（rogue）

看了一局完整流程：大厅 → 游玩 → 升级三选一 → 暂停。升级面板（落笔 Lv.2，三张选项卡 + 键位 + 重掷）品质是够的，没动。
真正的问题在相机：

| 问题 | 原因 | 处理 |
| --- | --- | --- |
| 屏幕越大，场面越空、还越简单 | `zoom` 固定 0.82，1440 宽能看到 1756 世界单位、1920 能看到 2341；墨点只有十几像素 | `zoom = w < 620 ? 0.74 : clamp(w/1200, 0.82, 1.3)`，可见世界宽稳定在 1200 上下 |
| 宽屏上敌人在画面里凭空冒出来 | 出生距离拿**屏幕像素**当**世界距离**用：`max(view.w, view.h)/2 + 70`，而视野半宽已经是 `w/(2*zoom)` | 新增 `offDist(extra)`：按视野对角线一半（世界单位）算，三处出生点（散兵 / 波次 / 墨潮事件）共用 |

改后 1440 宽下角色从约 40px 涨到约 62px，敌人从 18px 涨到 26px，场面读得清了；换台显示器看到的是同一场仗。

### 01 纸上军团（legion）

| 问题 | 处理 |
| --- | --- |
| 横屏手机（844×390）点将台三行互相压：中间行被压到 21px，英雄列表（544px）盖在「开始守卫」上 | 宽够高压不够（≥700 宽且 ≤560 高）时改回两栏：左边点将台可滚、右边开始栏固定；标题收紧、装饰与重复说明隐藏。`height:calc(100dvh - 26px)` + `align-items:stretch` 让中间行真正可滚而不是溢出 |
| 桌面英雄卡 265px 高、内容只占 170px，底下空一大块 | Q 技那行（自带虚线分隔）`margin-top:auto` 钉到卡片底边，空白变成"正文 / 页脚"之间的呼吸 |

战斗内页（棋盘 / 招贤榜 / 道具 / 遣散条）看过两波，布局与信息密度是好的，没动。

### 05 砖块（brick）

手牌与盘子不同比例：盘子格子 91px，待放的三块固定 22px，差四倍，看着不像同一副砖。

- `brick.ts` 的 `fit()` 量出盘子格子写进 `--brk-cell`；
- `games/brick.css` 里 `--brk-tcell: clamp(13px, calc(var(--brk-cell) * .5), 40px)`，手牌取盘子的一半。

桌面 91 → 40，手机 42 → 21。**注意**：这一台的私有样式在 `games/brick.css`，
`.pane-brick .brk-tray .bp-grid i`（0,3,1）会盖掉写在 `hall.css` 里的 `.bp-grid i`（0,1,1）——
第一版写在 hall.css 里没生效，移到私有层才生效。八台都有这样的私有 CSS 层，以后改样式先看那一层。

### 收场态（砖块 / 叠山）

用各台自带的 QA 钩子铺残局（`BOARD.__seed / __setPieces / __checkStuck`、`MG_STAGE.__r2.setBoard / failNow`）触发失败：

- 判词文案与印章正常（「放不下了 · 0 行 / 0 分收场」「推不动了 · 3720 分 / 最高一枚「沙」」+ 朱印「散」），重开复位正常。
- **但判词压在盘子最后一行上**：`.pane > .verdict` 是绝对定位浮在台面底沿的，砖块 / 叠山的盘子吃满整台，那行字直接糊在砖上。
  处理：给判词一张自己的纸 —— 收到内容宽、居中、墨边 + 硬阴影，从"字糊在盘上"变成"盘面落了款"。台面尺寸一点没动。
- 叠山收场没有降透明度（砖块 / 破砖有），补上同一口径。
- 手机上叠山有一排方向键，判词纸签正好盖住它：竖排抬到 `bottom:138px`、横屏 `144px`，让开方向键。
