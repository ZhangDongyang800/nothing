# 设计规范 · Neo-brutalism Lite

> 本文记录已删除的 B 长页设计。现役首页「六台机器」沿用同一套纸黄、粗边、硬阴影令牌，但布局与交互以 `src/themes/hall/` 和 `README.md` 为准。

## 色板

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--nb-paper` | `#FFF8E8` | 页面底色、浅色卡片 |
| `--nb-ink` | `#252525` | 正文、边框、深色面板 |
| `--nb-yellow` | `#FFD166` | 导航、贴纸、高亮、强调 |
| `--nb-blue` | `#9CC7F5` | 界面区背景、AI 卡 |
| `--nb-coral` | `#F28B82` | 句号、下载区、强调阴影 |
| `--nb-green` | `#A8C7A0` | 连载卡、流程块 |

黄、蓝、珊瑚、绿只用于有信息含义的块。正文区域保持纸色或墨色，不让所有元素同时抢注意力。

## 字体

- 正文：`HarmonyOS Sans SC / PingFang SC / Microsoft YaHei` 系统中文无衬线栈。
- 重标题：`Arial Black / Helvetica Neue / Microsoft YaHei`，字重 900，负字距。
- 标签与编号：`Cascadia Mono / JetBrains Mono / Consolas`。
- 首屏 H1 使用 `clamp()` 随视口缩放，桌面约 120px，移动端约 64px。

## 布局

- 最大内容宽 `1440px`，左右留白 `4vw`。
- 导航高 70px，sticky 顶部；锚点区块 `scroll-margin-top: 92px`。
- 首屏：12 栏不对称网格，左侧黑色文案面板 7 栏，右侧倾斜键盘照 5 栏。
- 能力区：首行 7 + 5 栏，次行 4 + 4 + 4 栏；五张卡对应五个能力。
- 流程区：四等宽色块横排，移动端 2×2。
- 下载区：黑色文案 + 黄色 2×2 facts 面板，珊瑚底色。

## 图片

唯一摄影素材 `public/images/brutal-keyboard.jpg`：黑白键帽极近特写，硬光长阴影。只用在首屏，蓝色粗框 + 倾斜 + 贴纸。四个产品界面示意由 `ProductShot` 绘制，不使用截图。

## 动效

- 滚动显现：`animation-timeline: view()`，标题与内容块淡入上移。
- 按钮/卡片 hover：位移与硬阴影变化，短时长。
- `prefers-reduced-motion: reduce` 下关闭所有滚动动画与过渡。

## 交互

- 能力卡：整卡覆盖透明按钮，打开 `role="dialog"` 详情；`Esc` 关闭，焦点限制在弹层内，关闭后回到触发卡。
- 界面卡：点击大图或右上角「放大 ↗」贴纸打开 Lightbox；界面标签直接打开对应图；`←` / `→` 换图，底部显示标题、说明与 `02 / 04` 计数。
- 流程卡与首屏贴纸是锚点链接，整卡可点。跳转后目标区块停在导航下方 92px。
- 弹层打开时锁 body 滚动并补偿滚动条宽度；能力层宽 `min(920px, 94vw)`，Lightbox 宽 `min(960px, 94vw)`，都在 `88svh` 内。
- 大图预览额外用黑色顶栏 + 「关闭 ×」，底部说明与翻页按钮固定可见，不折进滚动区。

## 响应式

- 1100px：收紧能力网格与页脚。
- 900px：首屏单列，导航折叠为汉堡菜单，能力卡单列，弹层改为 96vw / 92svh，详情要点单列。
- 520px：标题降级、图片全宽、流程 2×2、下载 facts 保持 2×2、Lightbox 翻页按钮缩到 44px。

## 适用场景

产品官网、独立工具落地页、需要有强烈品牌记忆点但不想牺牲阅读效率的站点。不适合内容密度极高的文档站或需要克制、正式语气的机构站。
