# 墨潮 / 纸上军团 · 美术表现与操作反馈升级（2026-11-25）

第三轮。前两轮修的是 bug 与外壳，这一轮只动两台旗舰的**画面本体**：造型、材质、特效、反馈。
沿用 React 外壳 + TS 模块 + Canvas 2D，没有换架构、没有删玩法、没有引入外部素材。

代表图：`docs/img/墨潮与军团-造型升级-2026-11-25.jpg`（上：墨潮十一种敌人同屏；下：军团十兵种布阵 + 土路）。

---

## 一、审查结论：问题出在哪

通读两台绘制层后，问题不是"颜色不够好看"，是**形状与反馈的信息量太低**：

**墨潮**（`rogue/draw.ts` 1039 行）

- 11 种敌人里 9 种是 `arc()` 画的圆或椭圆，只有重墨是梯形、咒者是三角。玩家在两百个墨点里分不出谁是谁。
- 死亡全部共用一句 `scale = dieT/0.3` + `alpha 0.7`，两百只死法一模一样。
- 受击只换填充色（`#ffc9b9`），没有形变、没有飞溅。
- 弹体无拖尾；光柱是两根线、链是折线、冲击波是一个匀速放大的圆。
- 粒子只有 dot / splat / line 三种，且统一 `vx *= 0.94`，没有材质差别。
- 玩家本体是一个黑圆加一根线，跟敌人的圆混在一起。

**军团**（`legion/draw.ts` 1032 行）

- 所有兵种是同一个墨黑圆角方块，只有中央汉字和品质色不同。
- 所有敌军是同一个圆角方块（`radius*1.9`，圆角 `radius*0.28`），九个兵种轮廓完全一致。
- 箭 / 弩 / 火球统一画成"淡光圆 + 短痕 + 实心小圆点"，没有形状差异。
- 普通弹道命中**没有任何粒子**，只有溅射才出冲击波。
- 地面是纸 + 方格 + 黄路 + 箭头，没有材质与空间层次。

---

## 二、艺术方向

两台不共用一套效果。

**墨潮 —— 志怪墨卷。** 纸是底，墨是形，朱砂只指危险。敌人不是几何体，是"活过来的墨"：
立起来的墨滴、梭形的疾影、鼓胀的爆囊、蛛形的织网、披袍的咒者。轮廓先说话，颜色再说话。

**军团 —— 桌面兵棋。** 文字棋子是 v3 定下的核心识别，**保留不动**。
升级走"立体兵牌"而不是改回小人插画：牌有厚度、有落地投影、按职能切角、底部挂兵器徽记。
地面从"黄方块"变成有路肩和碎石的土路，布阵格从"白方框"变成陷进沙盘的落子位。

## 三、关键技术决策：造型复杂度与帧时间解耦

要做出志怪轮廓，每只敌人得十几条路径。两百只 × 十几条路径 × 60 帧，主线程扛不住。

新增 `rogue/ink.ts`：**把静态造型预渲染进离屏 canvas**，按 `种类 + 半径 + 受击` 缓存（2× 超采样），
每帧只 `drawImage`，再叠很少的动态层。受击闪朱不是叠色，是**取另一张预渲染的 flash sprite**。

- 缓存上限 96 张，超出整批清空（半径随精英/缩放变，长局不会越堆越多）。
- 纸垫改成**径向渐变柔边**。第一版用硬边白圆，截图一看每只敌人都像贴在圆片上的贴纸 —— 这是本轮返工的一处。
- 实测 237 只敌人：中位帧时 **16.7ms**、p95 **17.7ms**（满 60fps）。

## 四、实际改了什么

### 墨潮

| 项 | 改动 |
| --- | --- |
| 敌人造型 | 11 种全部重画：墨卒（立墨滴）、疾影（梭形分叉尾）、投笔（立笔 + 铜箍 + 朱尖）、重墨（塌角墨岩 + 裂纹）、爆墨（鼓囊 + 裂缝透火 + 引线）、裂墨（锯齿裂缝两半错开）、织网（蛛形六折腿）、盾墨（墨核 + 六卡榫）、幽影（鬼面波浪摆）、咒者（披袍 + 兜帽 + 符）、碎墨（残片） |
| Boss 造型 | 5 个重画：墨牛（外挑双角 + 鼻梁 + 鼻环）、纸鸢（折纸折面 + 尾飘带）、碑灵（碑额 + 刻槽 + 朱封 + 悬浮碎石）、墨龙（龙首 + 鬃 + 须 + 甩身）、执笔人（袍影 + 巨笔） |
| 敌人动画 | 每种独立呼吸节律；疾影顺速度整只转、其余小幅倾斜；受击沿方向挤压回弹 |
| 死亡 | 按材质分四类：石类翻滚坠 + 碎块、幽类上飘消散 + 烟、蛛类断丝、火类炸火星；精英额外一道冲击锋 |
| 玩家 | 从黑圆改成"一管活笔"：木杆 + 铜箍 + 墨锋 + 飞白 + 双眼，走路有起伏 |
| 弹体 | 六种各有形与尾：笔锋拖墨、针带尾羽、刃自旋月牙、火吐焰舌；尾迹按速度三段递减残影（不用每帧新建 gradient） |
| 光柱 | 从两根线改成四段：外晕 → 两端收锋的墨带 → 亮芯 → 命中端光斑；前 15% 劈开、之后收锋 |
| 链 | 主干每段中点法向抖动（跳击而非画好的折线）+ 双层描边 + 每跳节点炸光 |
| 陨石 | 预警圈收拢 + 十字准星 + 旋转虚线；落体是墨石 + 火尾，越近地尾越短 |
| 冲击波 | 薄锋在前、宽淡余波在后 + 锋上十道放射短线 |
| 粒子 | 新增 shard / spark / smoke 三种材质，六种各有画法；物理按材质分：碎块坠、烟升、墨溅快速滞住、火星带重力 |
| 命中 | 新增定向喷溅 `spray()`：墨往被打的那一侧飞；暴击加金火星 + 薄锋 + 轻微震屏；打在护盾上溅金色火星 |

## 七、遗留与判断

- **裂墨在小半径下仍偏"圆"。** 裂缝已加宽、两半错开量从 0.09r 提到 0.2r，但 r=16 时整体读感还是接近圆团。要彻底分开得改成非对称双瓣，会动到碰撞半径的视觉预期，本轮没做。
- **军团兵器徽记在 cell < 70 时仍偏小。** 已从 0.082cell 提到 0.098cell，再大会压到主字。小格子走文字回退。
- **军团地面只做了材质，没做地形装饰。** 9×9 全部是路格或布阵格，没有空地可以放树石。要加装饰得动棋盘布局，属于玩法边界，本轮不动。
- **墨潮飘字仍会偶发重叠**（"连击 ×120" 压住 "+16%"）。这是既有的文本排布问题，与本轮造型无关。
- 本轮没有改动任何数值、碰撞、掉落、武器逻辑与操作按键。
